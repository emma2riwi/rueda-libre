# Rueda Libre

Página de Rueda Libre, un emprendimiento de alquiler de bicicletas y recorridos guiados en Medellín. Tiene inicio, tarifas y reservas, hechas con HTML, CSS y Bootstrap (navbar, grid, cards, carrusel, tablas, formulario, modal y alerta).

Sitio publicado: https://emma2riwi.github.io/rueda-libre/

Fotos de Wikimedia Commons: alquiler.jpg ("Bikeshare Zhengzhou", Henrysz, CC BY-SA 4.0), recorridos.jpg ("Recorrido en bicicletas públicas por la ciudad de Medellín", Cancillería Ecuador, CC BY-SA 2.0) y taller.jpg ("Hilltop Bicycles Summit NJ", Tomwsulcer, CC0). El logo lo hice con Gemini.
