# Rueda Libre

Página de Rueda Libre, un emprendimiento de alquiler de bicicletas y recorridos guiados en Medellín.

- Con Bootstrap: el sitio principal (inicio, tarifas y reservas), con navbar, grid, cards, carrusel, tablas, formulario, modal y alerta.
- Con Tailwind: la carpeta `rueda-nocturna/`, una landing de los recorridos de noche hecha con el Play CDN y clases como `sm:`, `md:` y `lg:` para el responsive.

Sitio publicado: https://emma2riwi.github.io/rueda-libre/
Rueda Nocturna: https://emma2riwi.github.io/rueda-libre/rueda-nocturna/
