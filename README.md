# Rueda Libre v1.0

Sitio web informativo de Rueda Libre, un emprendimiento de alquiler de bicicletas y recorridos guiados en Medellín. Proyecto del módulo T1.1 HTML y CSS de Riwi.

**Sitio publicado:** https://emma2riwi.github.io/rueda-libre/

## Páginas
- `index.html`: inicio, con portada, servicios, pasos para alquilar y beneficios.
- `paginas/tarifas.html`: tablas de alquiler y de recorridos guiados.
- `paginas/reservas.html`: formulario de reservas con validación nativa.

## Tecnologías
- HTML semántico (header, nav, main, section, article, aside, footer).
- CSS en una sola hoja externa (`css/styles.css`), con variables, Google Fonts (Montserrat y Open Sans), modelo de caja y posicionamiento.
- Git y GitHub Pages.
